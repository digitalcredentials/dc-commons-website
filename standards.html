Standards

Digital credentials work across schools, wallets and employers because they’re built on shared open standards. These are the standards we support, the version of each, and how far our support goes.

What the statuses mean

Emerging
We are tracking the development of this standard, which may develop into an important standard for us and our members to implement in the future.
Developing
We are supporting the development of this standard and/or software that implements it, but it is not yet ready for the community to broadly rely on.
Implemented
We implement this standard in relevant DCC software and we recommend our members use it for relevant work. It is active and adequately mature.
Deprecated
Often when replaced by a better option, we stop recommending implementation of a standard or version. It may still be supported where needed, for example to verify older credentials. Notes name the replacement.

Problem types

As part of our work defining what makes a valid credential, we’ve named the problems that verification software can find. Our software uses these names, and other implementers are welcome to use them too.

Each one has its own address, such as https://dccommons.org/standards#CREDENTIAL_REVOKED, so an error report can link straight to what it means. Problems that a W3C specification already names use that specification’s address and aren’t listed here.

CHALLENGE_REQUIRED Challenge Required
The verifier was given a domain to check on a presentation but no challenge; a domain can only be checked together with a challenge.
CHECK_ERROR Check Error
A verification check failed to run because of an unexpected error, so it reached no result.
CREDENTIAL_EXPIRED Credential Expired
The credential’s validity period has ended; its signature is genuine, but it is out of date.
CREDENTIAL_NOT_YET_VALID Credential Not Yet Valid
The credential’s validity period has not started; its signature is genuine, but it cannot be used yet.
CREDENTIAL_REVOKED Credential Revoked
The issuer has revoked the credential through its status list.
CREDENTIAL_SUSPENDED Credential Suspended
The issuer has suspended the credential through its status list.
HTTP_ERROR HTTP Error
A web request needed to check the signature failed, for example fetching a JSON-LD context.
ISSUER_KEY_MISMATCH Issuer Key Mismatch
The key that signed the credential belongs to someone other than the credential’s issuer.
ISSUER_NOT_REGISTERED Issuer Not Registered
The issuer was not found in any of the issuer registries the verifier could check.
PROOF_TYPE_UNSUPPORTED Unsupported Proof Type
The verifier has no way to check this kind of proof.
REGISTRY_ERROR Registry Lookup Error
Looking up the issuer in the issuer registries failed with an unexpected error.
REGISTRY_UNCHECKED Registry Unchecked
One or more issuer registries could not be reached, so the issuer’s registration could not be fully checked.
SCHEMA_VALIDATION_ERROR Schema Validation Error
The credential could not be checked against its JSON Schema because the validation itself failed.
SCHEMA_VALIDATION_FAILED Schema Validation Failed
The credential does not match the JSON Schema it was checked against.
STATUS_LIST_ERROR Status List Error
Checking the credential’s status list failed for an unexpected reason, so its revocation or suspension status is unknown.
STATUS_LIST_EXPIRED Status List Expired
The status list credential is genuine, but its validity period has ended.
STATUS_LIST_ISSUER_MISMATCH Status List Issuer Mismatch
The status list was not issued by the credential’s issuer. This is a warning: some status services sign every list with their own key.
STATUS_LIST_NOT_YET_VALID Status List Not Yet Valid
The status list credential is genuine, but its validity period has not started.
STATUS_LIST_TYPE_ERROR Status List Type Error
The document named as the credential’s status list is not a BitstringStatusListCredential.
VERIFICATION_METHOD_UNRESOLVED Verification Method Unresolved
The key that signed the credential could not be found: the issuer’s DID document could not be fetched, or it does not contain the key the proof names.

These types apply to Open Badges credentials.

OB_DECLARED_SCHEMA_MISMATCH Declared Schema Does Not Match Credential
The credential’s credentialSchema names a known Open Badges 3.0 schema meant for another credential type or VC version; the credential was checked against the schema that fits it instead.
OB_DECLARED_SCHEMA_NOT_CHECKED Declared Schema Not Checked
The credential’s credentialSchema names a schema that is not a known Open Badges 3.0 schema, so it was not checked; the credential was checked against the Open Badges schema for its type and VC version instead.
OB_INVALID_ACHIEVED_LEVEL Invalid Achieved Level
A result’s achievedLevel is not one of the rubric levels declared in the ResultDescription it refers to.
OB_INVALID_RESULT_REFERENCE Invalid Result Reference
A result refers to a ResultDescription id that the achievement does not define.
OB_MISSING_RESULT_STATUS Missing Result Status
A result whose ResultDescription has resultType "Status" has no status value.
OB_UNKNOWN_ACHIEVEMENT_TYPE Unknown Achievement Type
The achievement’s achievementType is not in the Open Badges vocabulary and does not use the ext: prefix that extensions must use.
